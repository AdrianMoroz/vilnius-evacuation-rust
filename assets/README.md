# Vilnius road network

The bundled `roads.json` is the OpenStreetMap-derived road snapshot used by the Vilnius evacuation browser prototype. The snapshot is dated 2025-09-25 and includes 7,856 nodes, 10,316 road segments, and 18,422 directed edges.
